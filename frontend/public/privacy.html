AutoTube – Privacy Policy

Last updated: 5 November 2026

AutoTube is a private tool used by its owner to create videos and publish them to the owner's own YouTube channels (WealthSutra, Kahani Pitara, Apna Motivation). It is not offered to the public.

What data we access

When a channel owner clicks “Connect YouTube”, Google asks for permission to manage that YouTube account. AutoTube uses this permission only to:

  • upload videos, thumbnails and subtitles to the connected channel,
  • add those videos to the channel's playlists,
  • read the channel's name and public statistics to show them on the dashboard,
  • search public YouTube videos to choose relevant tags and topics.

AutoTube does not read, store or share viewers' personal data, comments, messages, or any data from other channels beyond public search results.

How data is stored

The OAuth tokens Google issues are stored in a private database used only by AutoTube, so uploads can continue without signing in each time. Video scripts and processing logs are stored in the same database. Nothing is sold or shared with third parties.

Use of Google user data

AutoTube's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. AutoTube uses the YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time from Google Account → Third-party access. The stored tokens are then useless and are deleted when the channel is disconnected in AutoTube.
